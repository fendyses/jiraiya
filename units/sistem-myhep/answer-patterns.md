## E-AKTIVITI
*From 254 tickets (Jan–Sep 2026), answered by all staff. 116 were closed with the generic canned #3, so they have no reusable answer.*

Most e-Aktiviti problems come down to **society (persatuan) setup**. Check in this order: society active? → student is a member? → active advisor? → society added to a fund (tabung)?

### A. `persatuan-tidak-aktif` — society/club name missing from the dropdown, cannot continue
**Signals:** "nama persatuan tidak muncul/keluar", "tiada pilihan kelab", cannot fill the Kelab Persatuan tab.
> Semakan mendapati persatuan tersebut tidak aktif. Setiausaha persatuan perlu membuat permohonan pembaharuan persatuan dan mendapatkan kelulusan terlebih dahulu sebelum boleh membuat permohonan aktiviti.

### B. `bukan-ahli` — society is active but the applicant isn't a member
> Semakan mendapati anda tidak berdaftar sebagai ahli persatuan tersebut. Hanya ahli sahaja yang boleh memohon aktiviti. Mohon semak status keahlian dengan setiausaha persatuan.

### C. `tabung-tiada` — fund list shows only "TIADA MAKLUMAT"
**Signals:** "tiada pilihan tabung", "had tabung", "tabung kegiatan pelajar tidak dipaparkan".
> Mohon hubungi Bahagian HEP Kampus (Moderator HEP Cawangan) untuk menambah persatuan anda ke dalam senarai tabung. Hanya persatuan yang telah didaftarkan dalam Tetapan Tabung HEP boleh membuat permohonan aktiviti. Sekiranya persatuan tidak aktif, setiausaha perlu membuat pembaharuan persatuan terlebih dahulu.

### D. `penasihat-tiada` — no advisor listed / cannot save and continue
> Hanya persatuan yang mempunyai pegawai penasihat berstatus AKTIF dibenarkan memohon aktiviti. Mohon hubungi moderator aktiviti cawangan atau pengerusi persatuan untuk penetapan penasihat (MyPersatuan → Penasihat → Mohon).

### E. `form-error` — error on "Simpan & Seterusnya" / cannot submit
- Required fields → `Pastikan semua medan bertanda (*) diisi dan lampiran dimuat naik. Sekiranya masih berlaku, mohon sertakan screenshot keseluruhan page.`
- Attachment → `Dokumen hanya dibenarkan dalam format PDF, JPEG atau PNG sahaja.`
- Recurring dates → `Sekiranya aktiviti berulang, masukkan setiap tarikh berulang. Jika tidak, pilih TIDAK pada medan Aktiviti Berulang.`
- Less than 4 weeks before the event → allowed, but a surat tunjuk sebab must be attached
- Fund "tanpa biaya" → cost must be RM0, or ask the moderator to raise the fund's maximum cost

### F. `kembalikan-permohonan` — reviewer/approver asks to return an application (budget change, wrong decision)
Action: return it to the Penyemak, then reply `Aduan telah diselesaikan. Permohonan telah dikembalikan kepada Penyemak.`
- Approved activity: `Pindaan perbelanjaan tidak dibenarkan bagi aktiviti yang telah diluluskan. Sila batalkan permohonan dan kemukakan semula.`
- Delete request: cannot delete (kept for records). The Penyemak submits to the Moderator, who sets it to "Tidak Disokong".

### G. `system-rules` — how the system works (not a bug)
- Export error → enter a search filter first, then export
- No kertas kerja shown → the data entered in the system replaces the kertas kerja
- Approval letter → only the applicant can download it
- Expense details → only shown for approved (Lulus) applications
- Off-campus approval letter → not in MyHEP yet, follow the old manual procedure
- Reporting (laporan) module → still being improved or tested
- Improvement request → submit a CR at bsm.uitm.edu.my, or send it to PKP HEP for evaluation

### Misc
- Not enough info → ask for the student ID, society name and a screenshot (canned #6 / #16)
- Non-ICT policy question (e.g. changing a fund) → canned #5, refer to the campus HEP (Penolong Pendaftar HEP)
