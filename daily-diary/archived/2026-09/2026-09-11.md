## 2026-09-11 (Afternoon - 12:32 PM) - MyAlumniCard Registration API Recovery

### Session Summary
- Type: Work
- Focus: Diagnose and repair the registration verification request that appeared as a CORS failure.
- Outcome: Local verification now uses an Angular same-origin proxy, production bypasses the Angular service worker for this API call, and the rejected `myatp` token was replaced with the working `alumnai` token.

### Main Topics Discussed
1. Traced the production Network sequence from HTTP 504 through `ngsw-worker.js` CORS and preflight failures.
2. Confirmed the public MyAlumniCard frontend resolves to `199.36.158.100`, while `fastapi.uitm.edu.my` resolves inside UiTM to private address `10.0.37.50`, making Chrome Local Network Access relevant.
3. Probed FastAPI CORS behavior: ordinary authorization preflight returned 200, while a private-network preflight returned 400 with `Disallowed CORS private-network`.
4. Added `ngsw-bypass=true` for production and an Angular development proxy at `/alumnai-api` so localhost no longer calls the private API cross-origin.
5. Used Fendy's localhost Network capture to prove the proxy worked: the request reached `127.0.0.1:4200` and the failure changed from CORS to a real 401 response.
6. Retrieved the backend authentication message, `Token mempunyai tandatangan tidak sah (invalid signature)`, then verified the existing `alumnai` token against `/alumnai/semak` with harmless placeholder data and received HTTP 200.

### Key Insights & Learning
- The browser's CORS label hid two independent failures: a gateway timeout and a rejected private-network preflight.
- Angular's service worker cannot trigger Chrome's Local Network Access permission prompt, so bypassing it is necessary for this cross-origin request.
- In local development, a same-origin Angular proxy is the dependable path because `ng serve` does not need the production service worker and the browser never contacts the private address directly.
- The old registration token was not expired; FastAPI rejected its signature. The repo's newer `alumnai` token had a valid signature and adequate scope.
- Bearer tokens embedded in Angular remain visible in the browser bundle; a server-side credential proxy is still the safer long-term design.
