## 2026-09-09 (Afternoon - 5:00 PM) - NRHome: Quasar 2 Aborted, Then Four Production Bugs

### Session Summary
- Type: Work / Debug / UI overhaul
- Repo: **NRHome** (`/Applications/Sites/nrhome`) — UiTM
- Focus: Evaluate a Quasar 2 upgrade; after it was called off, fix live production defects and modernise the UI
- Outcome: 11 commits pushed to `origin/main` (`1cacf2d` → `a7183f1`). Quasar 2 upgrade built and verified, then reverted on request. Four real production bugs found and fixed instead.

### Main Topics Discussed

1. **Quasar 1 → 2 upgrade — completed, then reverted.** The survey found a remarkably clean codebase: no template filters, no `.sync`, no `slot-scope`, no event bus, no `.native`. Built the whole thing on `upgrade/quasar-2` — deps, 9 boot files, Vuex 4, vue-router 4, `vuejs-jwt` removal, template fixes — and `quasar build` passed with zero warnings. Fendy then decided not to upgrade this time; reverted cleanly, branch preserved at `0690a49`.

2. **Getting `main` to run locally at all.** Three separate blockers on Apple Silicon + Node 24: `electron@9.4.3` has no darwin-arm64 build (404 on postinstall); `websocket-driver@0.6.5` calls `process.binding('http_parser')`, removed back in Node 12; and every API call is CORS-blocked because the gateway allowlist contains the production origin only. Solved with `--ignore-scripts`, an npm override to `websocket-driver ^0.7.5`, and a `devServer.proxy`.

3. **`is_available` typed as string — houses could not be saved at all.** Landlords filled every field, pressed Simpan, and got "Maklumat yang dihantar tidak lengkap atau tidak sah." The gateway declares `is_available: string | null`; the SPA sends a boolean; Pydantic v2 rejects with 422 before the endpoint runs. Proved it against production with a safe probe — omitting the required `token` guaranteed a 422 and made a write impossible — and the API named the field itself.

4. **`zone` / `zone_campus` silently discarded.** The form collects both; the request model has neither; Pydantic drops unknown fields and still returns `200 OK`. Verified with a labelled test record (id 625): sent values, read back `null`. Then sampled 184 live houses — **0** have either field.

5. **Map pin broken on 54% of houses.** `google_map_url` is free text: of 104 production houses, 48 hold a real URL, 51 plain text, 5 coordinates. `openURL()` passed those to the browser, which resolved them as relative paths → `Cannot GET /Blok%2018%20flat%20pkns`.

6. **UI/UX overhaul.** Login redesign, glass surfaces across the shell and both house forms, form grids rebuilt into labelled sections, a standard search/filter panel, notification banner, account menu, uploader dropzone, and gradient primary actions.

7. **Photo upload moved into the add-house form.** Previously a landlord had to save, return to the list, press Details, then upload — and a house without photos is inactive, so many stopped halfway and left invisible listings.

### Key Insights & Learning
- **The gateway's read and write models contradict each other.** `GET` returns `is_available` as a real boolean while `POST`/`PUT` accept only a string. That one mismatch broke both add *and* edit.
- **Pydantic ignoring unknown fields is the dangerous default here** — a dropped field returns `200 OK`, so the loss is invisible to user and developer alike.
- **`.env.contoh` had quietly regained `TOKEN_API_INTEGRASI` + `SIGNKEY`** and repointed the API at `digitalcampus` — an old config restored over the current one. Flagged; `git log -S` confirmed the token never entered history.
- **One fix was wrong mid-session:** pointing the API at `digitalcampus.uitm.edu.my/api` per `.env`, which returns 403 because it still demands the removed service token. `api.uitm.edu.my` is correct and the `.env` is stale. Reverted.
- **Copying logic to a second place is how bugs survive fixes.** The pin had two implementations; fixing one and declaring victory left `/listing` broken. Now extracted to `functions/function-buka-peta.js`.
- **Unscoped `<style>` in a `.vue` file is global.** `EditHouse` set `.nr-uploader { height }` and it leaked into `NewHouse` once loaded.
