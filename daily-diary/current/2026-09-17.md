### Key Insights & Learning
- **The pencil icon in an application's Partners table is a global edit.** It opens `partners.modal.edit` and saves the shared row. The per-application swap lives on the Manage Legal Documents *listing* (green Edit Partner button, Admin-only), not on the show page. Two buttons that both say "edit partner" doing very different things is the root cause here, not the admin.
- **Pivot rows are an accidental backup.** `application_partner` snapshots contact person/email/phones at attach time. That's what let the SEDA contact be restored with confidence; the address wasn't snapshotted, so it wasn't.
- **Unique validation order matters when renaming in a swap.** Rename the wrong record away first, then create the right one. Otherwise MySQL's case-insensitive unique index blocks you.
- **`reference_no` is denormalised and only refreshed in two code paths.** Any new partner-changing UI (the Manage Partners modal is one) silently leaves it stale. Worth a code fix: regenerate on attach when the application has exactly one partner.

There is no null guard and the control has no `Validators.required`. The "not found" branch would leave an empty string, not null, so the null points at the first branch.

### Key Insights & Learning
- **A gate that also advances the status is not a gate.** `store()` moving MEU documents to LPU at draft time made the Approve click optional, and 970 healthy documents only look healthy because one person always clicks it.
- **Profile before caching.** The 5 s was one O(days) loop, not the database; a prefix sum removed 75 % of it with zero behaviour change and no invalidation story. The cache was the right *second* step, and Fendy was right to defer a stateful mechanism he hadn't asked for.
- **Never click a submit on a served copy of a real page.** The browser carries the user's session for the local site; a preview that looks inert can write to the database. Disarm form actions first, every time.
- **Global form handlers own the preloader.** Any handler that intercepts a submit (modal confirm, cancelled `confirm()`) must hide `#preloader` itself, and must be bound *after* `app.min.js` — inline `onsubmit` runs first and gets undone.
- **`array_filter()` on a request payload silently deletes every `0`.** It has been dropping `lpu_approval=0`, `priority=0`, `nominated_signatory=0` on the application edit page for as long as that line has existed.
- **A second assignment log is a hand-over, not a slower assignment.** Stage 1 must key on the first assignment after the latest arrival, or every re-assignment retroactively breaches the original.
