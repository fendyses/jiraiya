## 2026-07-31 (Afternoon - 12:23 PM) - NILAM LPU Draft Page 404 Investigation

### Session Summary
- Type: Investigation and bug fix
- Focus: Diagnose why `/lpuapprovals/create?id=6854` returned HTTP 404
- Outcome: Root cause confirmed, three affected controller joins corrected locally, and the fix left staged but uncommitted for Fendy to test

### Main Topics Discussed
1. Traced the LPU draft-email route into `LpuApprovalController::create()` and proved that application 6854 exists, is active, and belongs to LPU meeting 29.
2. Confirmed the failing inner join compared `ketua_ptj.kod_jabatan = A0644` against `users.department_code = FAKULTI SAINS KESIHATAN`, causing `findOrFail()` to return a misleading 404.
3. Verified user 71 is still correctly associated with Fakulti Sains Kesihatan through `department_id = 29`; only the `department_code` representation is malformed.
4. Updated the create, print, and edit-letter queries to resolve `ketua_ptj` through `applications.department_id → departments.code`.
5. Generated a two-page infographic incident report and saved it in the JIRAIYA repository under `docs/reports/incidents/`.

### Key Insights & Learning
- The application record was never missing; an incompatible inner join removed it before lookup completion.
- Application-scoped department identity is the correct source for historical workflow documents because a creator’s directory information can change or contain legacy values.
- The reported local 404 persisted once because the test URL used capital `I` in `/Ipuapprovals/`; the registered route uses lowercase `l` in `/lpuapprovals/`.

### Collaboration Highlights
- Fendy requested diagnosis first, reviewed the department-code interpretation, then approved a testable local fix.
- Production checks remained read-only, and unrelated Nilam changes were preserved untouched.

### Growth and Development Notes
- The investigation separated route errors, record existence, authorization, and joined-data availability instead of treating every 404 as a missing route or missing application.

### Memorable Moments
- `A0644 ≠ FAKULTI SAINS KESIHATAN` made the hidden identifier mismatch immediately visible.
