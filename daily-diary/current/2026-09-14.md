## 2026-09-14 (Afternoon - 4:22 PM) - MyAlumniCard: Serve Failure, Split-Horizon CDN, Hot Seat Table Rebuild

### Session Summary
- Type: Work
- Repo: MyAlumniCard (`/Applications/Sites/myalumni-angular`) — UiTM
- Focus: Unblock `ng serve`, diagnose broken production images, restructure the `/admin` Hot Seat Count table
- Outcome: Serve restored, production image failure fully explained (no app bug), Hot Seat table rebuilt and shipped in `7fff3b5` + `8e4f3bd`

### Main Topics Discussed

1. **`ng serve` would not start.** Three dependencies — `jspdf`, `html2canvas`, `@ng-select/ng-select` — were present in `package.json` and `package-lock.json` but absent from `node_modules`, left behind by commits `13b721d` and `bdd8dca`. The real cause was buried: three `Module not found` lines sat above roughly a hundred `NG8001: 'app-header' is not a known element` template errors. When `app.module.ts` fails to resolve an import the whole module fails to compile, so every component in it reports as unknown. `npm install` fixed it; build back to ~8.6s.

2. **Broken benefit images in production, fine on localhost.** Traced to **split-horizon DNS**: `cdn.uitm.edu.my` resolves to `10.0.21.69` (private) on the UiTM network but `202.58.84.29` (public) from outside, confirmed via DNS-over-HTTPS and a successful external fetch. The production page sits on `199.36.158.100` (public), so on campus it makes a public→private subresource request and Chrome's Private Network Access blocks it. Localhost is loopback, which moves toward the more-public end and is never a private network request — hence the difference. Verified the nginx `/media/` block answers the private-network preflight with a bare `204` carrying only `Access-Control-Max-Age`: no `Access-Control-Allow-Private-Network`, no `Access-Control-Allow-Origin`. The `GET` does carry `Access-Control-Allow-Origin`, but the preflight has already failed by then. **Conclusion: off-campus alumni are unaffected — this is Fendy's vantage point, not a production outage.** A same-origin proxy (Hosting rewrite → Cloud Function, which resolves the CDN publicly) was designed but not implemented, pending confirmation of the banner hostnames.

3. **Hot Seat Count table restructure (`/admin`).** The same `<table>` block was written three times (split part 1, split part 2, regular venues), and `splitLargeLocations()` hardcoded `'Dewan Agung Tuanku Canselor, UiTM Shah Alam'` to drive a two-column layout from TypeScript, forcing both total functions to walk three separate collections. Replaced with one ordered `HotSeatVenue[]`, each venue carrying its own `columns`, `totalCount`, `totalSeats`; the template loops `venue.columns` once. Totals collapsed to a single `reduce`. Added typed `HotSeatRow` / `HotSeatVenue` interfaces. Splitting is now row-count based (>10) and applies to any venue — a deliberate behaviour change, flagged for Fendy to confirm.

4. **Visual work on the same table.** Added a per-venue subtotal row (totals previously existed only as grand figures in the stats strip), moved the column divider onto the column wrapper so it spans full height with uneven rows, made it `border-top` when stacked below 768px, and set `table-layout: fixed` at 50/25/25 so the two side-by-side tables align.

5. **Two defects I introduced, both caught by Fendy.** First, the subtotal numbers rendered as bare text — `.hs-badge` was nested inside `.hs-table`, so it never applied outside a table. Lifted it to top level and added per-figure captions plus the `number` pipe, since "1618 3236" gave no indication which value was which. Second, `npm run build` failed on an `anyComponentStyle` budget; I had been verifying with `ng build --configuration development`, which does not enforce budgets at all.

### Key Insights & Learning

- **Verify Angular changes with `npm run build`, not a development build.** Budgets only run in the production configuration. A dev build passing says nothing about whether production will.
- **The budget was already the problem.** Measured the compiled CSS: 4,032 bytes before my changes against a 4,096-byte ceiling — 98.4% full, one small edit from breaking whatever that edit was. The config also had `maximumWarning` and `maximumError` both at 4kB, so the warning fired only at the moment the build failed. Raised to 6kB / 8kB (Angular's own default ratio is 4kB / 8kB).
- **Split-horizon DNS plus Chrome PNA is now a confirmed recurring UiTM pattern** — second occurrence in four days. 11 Sep was FastAPI at `10.0.37.50`; today was the CDN at `10.0.21.69`. The symptom each time is "works on localhost, broken in production", which invites hunting for an app bug that does not exist. Checking whether the host resolves to a private address should be the first move, not the last.
- **SCSS nesting is scope, not just organisation.** `.hs-badge` living under `.hs-table` looked tidy but silently made the class unusable anywhere else in the component.
- **Stacked errors hide their cause.** A hundred template errors from three unresolved imports; reading the top of the log rather than the volume of it was the whole fix.
