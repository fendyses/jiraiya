# README.md

Ringkasan Eksekutif

Profil data peribadi ini disediakan bagi menerangkan latar belakang dan pencapaian berimpak tinggi saya sepanjang perkhidmatan di UiTM untuk pertimbangan lantikan baharu ke Skim FA6 Penolong Pegawai Teknologi Maklumat.

Di kesempatan ini saya mengucapkan setinggi-tinggi penghargaan dan terima kasih kepada Pengurusan Eksekutif UiTM, Jabatan Digital, Universiti Teknologi MARA Cawangan Perlis dan seluruh warga UiTM di atas segala peluang dan tunjuk ajar sepanjang saya berkhidmat.

Amat besarlah harapan saya untuk terus berkhidmat dan menabur bakti di UiTM dengan peranan yang lebih besar ke arah mencapai visi UiTM sebagai universiti terkemuka dunia.

01

Sistem Pengurusan Stok
Kad Prihatin Siswa

Pembangun PenuhSeluruh UiTM

Membangunkan sistem untuk merekodkan stok kad prihatin siswa yang digunapakai di seluruh UiTM. Rekod stok adalah syarat wajib Bank Negara memandangkan kad mempunyai cip "bank card". Sistem ini memudahkan pegawai terlibat merekodkan stok.

02

Sistem eAduan UiTM

Front-endLaravel

Terlibat dalam pembangunan (front-end) sistem eAduan UiTM. Dibangunkan menggunakan framework Laravel, bertujuan untuk memberi nafas baharu kepada Sistem eAduan Korporat.

03

Sistem PPUiTM

Front-endQuasar

Terlibat dalam pembangunan (front-end) sistem PPUiTM. Dibangunkan menggunakan Framework Quasar sebagai platform Persatuan Pentadbir UiTM.

Sistem Pengurusan Majlis – DevOps

PembangunVue.js

Membangunkan Sistem Pengurusan Majlis – DevOps menggunakan Vue.js untuk melancarkan program tersebut. Sistem ini juga boleh digunakan semula untuk sebarang majlis akan datang.
